Case Study Lab Assignment: 
Smart Library Catalog System 
Problem Scenario: 
A university library wants to modernize its book cataloging system. They need a digital catalog that: 
∙ Allows storing books with unique ISBNs. 
∙ Supports multiple copies of the same book. 
∙ Allows users to search for books by title, author, or genre. 
∙ Tracks how many times a book has been borrowed (for analytics). 
The library expects students to develop a system that leverages HashMap in multiple intelligent  ways. 
Learning Objectives: 
∙ Practice using HashMap in various real-world scenarios. 
∙ Understand nested or composite data structures (HashMap inside another HashMap, or  with List/Set values). 
∙ Reinforce object modeling and encapsulation (i.e., Book, Catalog, Library classes). ∙ Improve ability to design efficient lookups and mappings. 
Key Requirements: 
1. Model a Book Class: 
∙ ISBN (String, unique) 
∙ Title (String)

Extend the Library Catalog System to: 
∙ Persist and retrieve data from files or a database. 
∙ Implement abstract methods defined in interfaces and abstract classes. ∙ Follow principles of OOP: encapsulation, abstraction, separation of concerns. 
Design Overview 
Let’s define: 
1. CatalogPersistence (Interface) 
∙ For abstraction over storage (File / DB). 
∙ Students must implement this. 
2. AbstractLibraryCatalog (Abstract Class) 
∙ Defines high-level structure. 
∙ Uses the interface CatalogPersistence for saving/loading data. 
∙ Contains common fields like the bookMap. 
Interface: CatalogPersistence.java 
package library.persistence; 
import library.models.Book; 
import java.util.List; 
import java.util.Map; 
public interface CatalogPersistence { 
 void saveCatalog(Map<String, List<Book>> catalog) throws Exception;  Map<String, List<Book>> loadCatalog() throws Exception; } 
∙ Map<String, List<Book>> catalog: the key is ISBN, values are multiple copies. ∙ Students can implement this via: 
o FileCatalogPersistence: using Java File I/O (e.g., serialization, JSON, CSV). o DatabaseCatalogPersistence: using JDBC and SQL.
Abstract Class: AbstractLibraryCatalog.java 
package library.core; 
import library.models.Book; 
import library.persistence.CatalogPersistence; 
import java.util.*; 
public abstract class AbstractLibraryCatalog { 
 protected Map<String, List<Book>> catalog = new HashMap<>();  protected CatalogPersistence persistence; 
 public AbstractLibraryCatalog(CatalogPersistence persistence) {  this.persistence = persistence; 
 } 
 // Common method to add a book 
 public void addBook(Book book) { 
 catalog.computeIfAbsent(book.getIsbn(), k -> new 
ArrayList<>()).add(book); 
 } 
 // Abstract methods to be implemented 
 public abstract void searchByTitle(String title); 
 public abstract void searchByAuthor(String author); 
 public abstract void searchByGenre(String genre); 
 public abstract void borrowBook(String isbn); 
 // Common persistence operations 
 public void saveCatalog() { 
 try { 
 persistence.saveCatalog(catalog); 
 } catch (Exception e) { 
 System.out.println("Error saving catalog: " + e.getMessage());  } 
 } 
 public void loadCatalog() { 
 try { 
 catalog = persistence.loadCatalog(); 
 } catch (Exception e) { 
 System.out.println("Error loading catalog: " + e.getMessage());  } 
 } 
}
